# Create Invite — Outlook add-in

Adds a **Create Invite** button to the message-reading toolbar in **New Outlook for
Windows** (also works in Outlook on the web and Mac). Click it on a scheduling email
and it:

1. Reads the open email (body + subject) and the sender.
2. Auto-detects the proposed time — e.g. *"Thursday at 11:00 AM"*, *"tomorrow 2:30 pm"*,
   *"quick 30 minutes"* — relative to when the email was sent.
3. Opens a **pre-filled meeting invite** (sender as required attendee, subject, start/end)
   for you to review and **Send**. Nothing is sent automatically.

If no time is found, it opens a blank invite and shows a note so you can set it manually.

---

## Why an add-in (and not a macro)?

New Outlook for Windows does **not** support VBA macros or COM add-ins. Office Add-ins
(the web model used here) are the only supported way to put a button in New Outlook.

## One-time setup

You need the files in this folder served over **HTTPS**. Two options:

### Option A — GitHub Pages (recommended, permanent, free)

1. Create a new **public** GitHub repo, e.g. `outlook-invite-addin`.
2. Copy this folder's contents into it and push.
3. In the repo: **Settings → Pages → Build from branch → `main` / root → Save**.
4. Your base URL becomes: `https://YOURUSER.github.io/outlook-invite-addin`
5. Stamp that URL into the manifest:

   ```bash
   node tools/set-base-url.mjs https://YOURUSER.github.io/outlook-invite-addin
   ```

   This writes `manifest.built.xml`. Sideload that file (next section).

### Option B — Quick local test (temporary)

Serve this folder over HTTPS on your machine, then use `https://localhost:PORT` as the
base URL. The add-in only works while the server is running.

```bash
# from this folder, using the office tooling (installs a trusted dev cert):
npx office-addin-dev-certs install
npx http-server -S -C "$(npx office-addin-dev-certs get | ...)" -p 3000 .
```

(Or any static server that supports HTTPS.) Then:

```bash
node tools/set-base-url.mjs https://localhost:3000
```

## Sideload into New Outlook for Windows

1. Open **New Outlook**.
2. Open any email so the reading pane is showing.
3. Top ribbon → **… (More apps)** → **Get Add-ins** (or **Apps**).
4. In the dialog: **My add-ins → Custom Add-ins → Add a custom add-in → Add from file…**
5. Select your **`manifest.built.xml`**.
6. Confirm. The **Create Invite** button appears in the toolbar when reading a message.

> Sideloading a custom add-in may require that your Microsoft 365 admin allows it.
> If "Add from file" is missing, ask IT to enable custom add-in sideloading, or use
> Outlook on the web (outlook.office.com) which exposes the same option.

---

## Test it

Open one of your scheduling emails (like the *"Thursday at 11:00 AM"* one) and click
**Create Invite**. A meeting compose window opens pre-filled — review the time and
attendees, then Send.

## Regenerating icons

```bash
node tools/make-icons.mjs
```

## Files

| File | Purpose |
|------|---------|
| `manifest.xml` | Add-in manifest **template** (contains `__BASE_URL__`) |
| `manifest.built.xml` | Generated by `set-base-url.mjs`; the file you sideload |
| `src/commands.html` | Hosts the button function (no UI) |
| `src/commands.js` | Reads the email, detects the time, opens the invite |
| `tools/make-icons.mjs` | Generates the PNG button icons |
| `tools/set-base-url.mjs` | Stamps your hosting URL into the manifest |
| `assets/icon-*.png` | Button icons |

## Tweaks

- **Default meeting length:** `DEFAULT_DURATION_MIN` in `src/commands.js`.
- **Subject format:** `buildSubject()` in `src/commands.js`.
- **Time patterns:** `findTime` / `findDay` / `findDuration` in `src/commands.js`.
